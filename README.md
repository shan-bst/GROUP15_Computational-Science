# GROUP15_Computational-Science
# Machine Learning: KNN and K-Means Implementations
This repository contains educational materials and practical Python implementations for two foundational machine learning algorithms: K-Nearest Neighbors (KNN) and K-Means Clustering. The content is structured to demonstrate both the manual mathematical processes and the programmatic solutions for each algorithm.Project Structure
# 1. K-Nearest Neighbors (KNN)
This section includes two distinct case studies: one for introductory learning (Student Dataset) and one for advanced application (Diabetes Dataset).
# Student Performance Prediction
Knn1.pdf: A manual walkthrough of KNN, detailing Euclidean distance calculations and majority voting using a small historical dataset of student attendance and quiz scores.
knn1.py: The Python implementation using pandas and scikit-learn/numpy to automate the calculation, sorting, and prediction process.
# Diabetes Classification
Knn2.pdf: A formal report covering preprocessing strategies, such as handling zero-value anomalies (imputation), normalization/standardization of features, and determining the optimal K value.
knn2.py: The corresponding Python script. It demonstrates data cleaning, standardization, and visualization of the nearest neighbors for specific patient instances.
# 2. K-Means Clustering
This section covers the basics of unsupervised learning through customer segmentation.Clustering Theory & CodeKMean1.pdf: Step-by-step documentation of the K-Means algorithm, explaining centroid initialization, iterative distance measurement, and cluster reassignment.kmean1.py: The Python implementation that uses numpy to define centroids and visualize the distribution of data points before and after clustering.
